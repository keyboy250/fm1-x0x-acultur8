Can this website open a raw REX file?

Use the matching WAV slice bank and marker JSON exported by a compatible converter. This static website has no native REX decoder. The local lab supports optional native conversion when its separate decoder is configured. SDK installation and distribution permissions remain separate from this public package.

Why can the WAV be longer than the loop?

The WAV packs each intact slice end to end, including its ringing tail. Marker startSample and endSample locate that sound in the bank. Marker time is its original musical onset in seconds. Adding slice lengths together would lose overlaps and gaps.

How does sync keep the pitch?

Play with FM1 · keep pitch schedules slice starts against the internal sequencer clock. Each slice plays at its original speed. At faster tempos tails overlap more; at slower tempos gaps may appear. This is slice sequencing, rather than continuous stretching of sustained audio.

If stopped, both start from beat one. If already playing, the loop joins the next four-beat bar. Instrument PLAY then stops and restarts both. Original loop length is retained: a 7/8 loop still spans 3.5 quarter-note beats. Enter its source BPM if the markers have none.

Which files belong together?

Choose the _slices.wav and _markers.json from the same export. JSON can carry sample rate, frame count, channels, BPM, loop duration and exact boundaries. Manual import validates the available dimensions. The local converter handoff also validates the WAV checksum.

CSV uses Slice,Start,End,Time in seconds, with an optional final Loop,,,duration row. Legacy Slice,Duration,Total CSV cannot recover the original onsets; re-export from the REX source. A rendered full-loop WAV is different from a packed slice bank.

Where does Save put my work?

Save import in browser stores the WAV and markers in this browser; Reopen saved import retrieves them. The instrument SAVE control stores instrument state separately. A different browser or website address has different storage. Keep your source files as a portable backup.

How do I use the kick strip?

Switch on the emulator, then enable the 909 kick strip and the stages you want. High-pass removes low frequencies; low-pass reduces high frequencies. Boost raises level into the limiter, and the negative dBFS ceiling caps the processed kick before pan and effect sends. Existing projects start bypassed. Use Undo/Redo for edits, and stop the sequencer before Save project. The other voices keep their existing sound.

This is a sample-peak limiter with no lookahead or true-peak claim. Effects and other sounds can still add together after the strip; keep the existing master protection. The browser prototype is accepted; physical-device performance remains pending.

How do I arrange blocks and chords?

Switch on the emulator, set Length while stopped and enable arrangement. Each block assigns five patterns, mutes, a duration of 1–8 four-quarter-note bars and an optional I–VII degree. Twelve pages cover 192 rows. Editing selects the row shown in the controls without moving playback. Queue chooses the next musical-bar transition, or the start block while stopped. The C engine displays the playing chord; bass-follow and accompaniment are still pending.

Choose the key and mode for diatonic triads. Pentatonic chords require an explicit seven-note parent; choose it before changing mode. Chromatic mode cannot hold I–VII degrees. Stop before length/enable changes, Undo/Redo of arrangement or Save project. Busy requests retain your current project and transport. Broader insert/duplicate/delete, row-order operations and loop-range controls are still being developed. The published basic arrangement and harmony metadata are already accepted.
