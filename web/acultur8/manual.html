BROWSER ALPHA / QUICK START

Get sound.
Then make it yours.

Your first loop

  1. Open the emulator and press its Switch on button. Browser audio starts after this click.
  2. Scroll to WAV + original slice markers. Press Load public demo · 120 BPM.
  3. Press Play original timing to hear only the original six-slice rhythm.
  4. Press Play with FM1 · keep pitch. The loop now follows the internal sequencer.
  5. Enter 90 or 180 in FM1 tempo (BPM) and press Set FM1 tempo. The hits move closer together or farther apart while their pitch stays the same.
  6. The instrument's PLAY control stops and restarts both. Stop slices stops the imported loop while the instrument pattern keeps playing.

Program alongside it

Use the instrument's part controls to choose drums or bass, then click the step keys and press PLAY. The panel responds to mouse, touch and the keyboard shortcuts shown beneath it. Hold the modifiers shown in that help panel for secondary actions.

Detailed existing instrument functions are described in the source manual. New Acultur8 controls appear only as their development milestones pass.

Import your own pair

  1. Choose the matching _slices.wav under WAV audio and _markers.json under Exact slice markers.
  2. Press Import WAV + markers. Check the displayed slice count, source sample rate and duration.
  3. For sync, confirm the Original loop BPM. Enter the source BPM if the markers do not contain it.
  4. Audition an individual slice pad, then Play original timing or Play with FM1.

Files are read by this browser. Downloading a WAV and its matching JSON from the demo section is a useful first importer test.

Save and reopen

Save import in browser stores the imported audio and markers. Revisit the same hosted URL and press Reopen saved import. The instrument's own SAVE preserves instrument state separately. Browser storage can be cleared by privacy settings; keep your original files.

Listening checks

Start with a modest output level. If silent, check the power button, the browser's audio permissions, your output device and the slice preview level. Try a single slice pad. Uncheck Layer with FM1 audio to hear only the slices while retaining synchronized timing.
