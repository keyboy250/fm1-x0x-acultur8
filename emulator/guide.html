Play the browser beta.

Switch on, then choose Unmute when you want sound. On a phone, swipe the instrument sideways or use landscape orientation. A mouse wheel or the arrow keys turns a focused knob. Tap the on-screen buttons; Shift-click holds a button for combinations.

Pattern tools

EDIT opens the selected part. Turn ALGORITHM to choose 909, 808, 303 A, 303 B or BREAK. ARP cycles the selected part’s generator and variation pages. The screen reader below the panel can read each page and changed value.

  • 303: the CONSTRAINED page selects note constraints, step length and a single step. OCT− repeats the selected seed; OCT+ requests a fresh one. Read the confirmation, then SEL to apply or HOME to cancel.
  • Drums: RHYTHM generates the selected lane. Black keys choose the sound; its generator controls include density, anchors and seed.
  • VARIATION and VAR OPTIONS set cadence, amount, anchors, seed and scope. Review and confirm ARM with OCT+ and SEL. Temporary variation keeps the stored base intact.
  • FREEZE / STORE captures a completed variation pass. Request Freeze with OCT+ during browser playback; wait for FROZEN. Stop, choose a different STORE TO pattern with KNOB1, then OCT− and SEL to commit or HOME to cancel.
  • GLOBAL → COPY/PASTE SEQUENCES chooses both patterns and compatible source/destination parts before confirmation. Use the browser panels’ Undo and Redo controls while stopped.
  • GLOBAL → CC MODE selects FULL, SIMPLE or OFF for this session. External MIDI input and output require separate, explicit connection.

Keep your work

SAVE keeps the project in this browser. This beta uses separate storage from the older public emulator. Browser storage is local to this browser and profile; clearing site data removes it. Factory reset affects this beta’s browser project.

WAV and exact slice markers

Select a WAV and its matching CSV or JSON marker file. CSV uses Slice,Start,End,Time in seconds. JSON uses sampleRate, loopDuration and slices with startSample, endSample and time. Use Load unequal timing demo to try a synthetic loop without uploading anything.

Convert REX in the local workbench first, then import its matching _slices.wav and _markers.json. This beta cannot convert raw REX files or upload slice settings to the FM-1. Audio and imported files stay in the browser.
