Tested, with clear boundaries

Local checks cover all 25 copy choices, production WASM menu/history/storage, 134 required checks and 39 host scenarios. The read-only service passed 2,557,290 strict sanitizer checkpoints and 9 Python reader tests. All 15 original target resource gates passed.

On one FM1: full 909 copy, kick/snare isolation and Undo were visually checked. A copied909 pattern retained accent step 2 and 60% swing through save/restart. New direct readback confirmed303 A-only and 808 kick-only copies changed only the intended lane, with source and other lanes unchanged; Undo restored baseline data and project fingerprints.

Experimental, not broad live-performance qualification. Other individual hardware scopes, heavy loads, receiver timing and power-loss behaviour remain separate checks. Existing autosave remains independent of the query.

Next on the development list

303 A → TD-3 MIDI channel1, independent internal-sound ON/OFF, a standalone Raspberry Pi MIDI router, named devices, weighted blocks and evolving probabilities are planned. They are not included in this download. Current MIDI output is USB; the FM1 TRS socket is input.

The browser emulator and Slice Profiles work remain available at their existing build state; this firmware release does not update them.
