Keep a rate sweep straight 2 min · device

Choose consecutive straight divisions without passing through dotted or triplet values.

  1. Start stopped

    Stop playback. Open GLO.

    Check: The Global settings list is visible.

  2. Choose the global policy

    Use SELECT to find SYNC RATE MODE at the bottom of the System section. Use ALGORITHM to choose STRAIGHT.

    Check: SYNC RATE MODE shows STRAIGHT.

  3. Try the kick rate

    Return HOME, select 909 BD, then press SEQ to find LENGTH and RATE. Select RATE at 1/16, then advance one position. If BD has a local override, first set EDIT → STRIP SYNC → RATE MODE to GLOBAL.

    Check: The next rate is 1/8, with no dotted or triplet stop between.

  4. Keep the setting

    Stop playback before further policy edits. Press SAVE and wait for SAVED when you want to retain your settings.

    Check: Existing rates were not rewritten by the policy change.

Straight kick, triplet snare 3 min · device

Build the rate relationship behind the “oom papa” example while keeping the kick straight. This changes rate settings; it does not create hits automatically.

  1. Keep the kick straight

    With playback stopped and global STRAIGHT selected, choose 909 BD. Set its strip RATE MODE to GLOBAL and its sequencer RATE to 1/16.

    Check: BD still shows 1/16.

    Select 909 SD. Press EDIT, use SELECT to find STRIP SYNC, and set RATE MODE to STR+TRIPLET.

    Press SEQ and set the snare RATE to 1/16T. Return to BD to check that its RATE is still 1/16.

    Use an existing pattern with kick and snare hits, or enter hits deliberately. Bring MASTER up cautiously for listening. Stop when finished; press SAVE only if you want to keep the edits.

    Check: The parts can use different divisions. The exact rhythm also depends on each sequence’s LENGTH and entered steps.

Current 0.1.32 answers

How do I use global straight time?

Stop playback. Press GLO and use SELECT to find SYNC RATE MODE at the bottom of the System section. Use ALGORITHM to choose STRAIGHT. ALL retains the full list.

STRAIGHT uses exactly:1/16, 1/8, 1/4, 1/2, 1/1, 2/1, 3/1, 4/1, 6/1, 8/1, 12/1, 16/1, 32/1. The3/1, 6/1 and12/1 choices mean whole-bar multiples, not triplet-labelled rates.

This filters subsequent rate choices. It does not silently rewrite existing pattern rates. Press SAVE when you want to retain your project settings.

Can just the snare use triplets?
  1. Select 909 and the snare (SD).
  2. Press EDIT; use SELECT to find STRIP SYNC.
  3. Set RATE MODE to STR+TRIPLET.
  4. Press SEQ and set RATE to 1/16T.

The kick can stay at 1/16 with its strip RATE MODE set to GLOBAL. Each of the 22 drum sounds, both 303 parts and BREAK has its own override: GLOBAL follows GLO; STRAIGHT always uses the 13-stop list; STR+TRIPLET permits the existing straight/triplet divisions without dotted entries; ALL permits the full list. Change policies while stopped.

Do the machines have separate tempos?

They share one global BPM. Their individual step RATE and LENGTH settings can differ. ALGORITHM selects the part; on HOME the highlight colour changes with it:909 orange, 808 red. Use SEQ to inspect that sound’s LENGTH and RATE.

How do I clear a pattern or only one part?

Whole current pattern: stop playback, open GLO → CLEAR PATTERN, check CLEAR THIS PATTERN? / ALL FIVE PARTS, then SEL confirms. HOME cancels.

Selected part only: select the intended part and pattern, hold SAVE and press REC. Check the named part, then SEL confirms or HOME cancels.

Clearing removes sequence data and keeps sound settings. Hold HOME and press REC for Undo, or HOME and PLAY for Redo. Undo history does not survive switching off. Stopped changes may save automatically when autosave is enabled.

Do the global mode and override survive restart?

Yes. Press SAVE and wait for SAVED. A bounded physical test confirmed both global STRAIGHT and 909 SD STR+TRIPLET after a normal power cycle, with repeated saved project exports byte-identical before and after. Save your pattern before switching off.

Does this fix Reason clock jitter?

No fix is claimed. Reason external-clock clip/grid stability remains unresolved. The 0.1.31 averaging/fine-tempo experiment is excluded from this build.

What about delay and LFO rates?

The shared delay knob uses its supported 1/16, 1/8, 1/4, 1/2 straight subset when global STRAIGHT is active. Its existing buffer/folding limit remains. Per-sound overrides govern that sound’s sequencing, not the shared send effect. This Extended Edition source has no separate LFO rate engine; the physical LFO button serves mixer/tie functions. Free-running parameters are unchanged.

How does MIDI rate control interact with this mode?

The rate sweep follows the effective global/strip policy. Explicit direct/exact MIDI rate IDs 0..20 keep their division meanings and are not silently remapped. Long divisions can be selected by the policy sweep or native exact-rate API after activation. No new direct CC address is assigned to the global/local mode selectors.

LAN2 family values remain0 straight, 1 straight+dotted, 2 straight+triplet, 3 all. After LAN3 activation, family CC value 0 selects a local STRAIGHT override, 2 selects STR+TRIPLET, and 1 or 3 selects ALL. See the version-matched MIDI chart for ranges, targeting and readback.

Can I open the new project in older firmware?

Keep a pre-feature project matched to your exact rollback firmware. LAN3 saves require compatible firmware and older builds deliberately reject them. Project exports do not independently export sample slots, panel calibration or the saved strip-default bank. Read installation and rollback guidance.

How much has been tested?

Local qualification passed 134 required checks and 39 host scenarios, native/WASM control and MIDI replay suites, calibrated timing, updater simulation, unchanged target budgets and an exact frozen-source rebuild. Installation preserved project bytes, 25 current strips, P8/P9 and calibration. Selected physical straight/override controls, listening and saved restart passed on one unit.

Advanced remote CC action hardware replay, worst-case physical deadlines, all voices/rates/tempos and Reason sync remain open. Read the scoped acceptance matrix.

Are alternate 303B engines and extra drum voices included?

Those are future-release requests. This build retains the existing 303 engines and 909/808 sounds; it does not add a synth-engine picker or new drum voice banks.

Extended Edition 0.1.9-query

Sequence tools, explained.

Copy and paste, preserve the destination groove, Undo, save and inspect patterns over USB.

What is new in 0.1.9-query?

Full-pattern and individual-lane copy/paste are joined by read-only pattern inspection. The menu offers25 scopes: ALL PARTS,11 rows for each drum kit,303 A and 303 B. BREAK is included in ALL PARTS; there is no BREAK-only scope.

How do I copy a whole pattern or just one part?

Stop playback. Open GLO → COPY/PASTE SEQUENCES, the top item above CLOCK OUT. Use SELECT to move between COPY FROM, PASTE INTO, COPY SCOPE and PASTE KEEP ACC/SW; ALGORITHM changes values. Select ALL PARTS, a drum row, or 303 A/B. Press SEL on PASTE KEEP ACC/SW, inspect source/destination/scope, then SEL confirms; HOME cancels. The chosen destination scope is replaced, not merged.

What stays unchanged at the destination?

Both shared drum-kit accent rows and pattern swing stay unchanged. Other lanes, sounds, strips, channel assignments and song references are retained for a single-part copy. Bass note accents, slides and ties belong to the bass sequence and do copy. A drum-only paste keeps shared legacy kit timing; in independent-lane mode, the selected lane’s timing copies.

How do I Undo or Redo the paste?

Leave the copy submenu and Global with HOME. With playback stopped, hold HOME and tap REC to Undo; hold HOME and tap PLAY to Redo. One paste is one transaction. Undo history does not survive restart. Check your pattern before saving; normal autosave remains independent.

How do I set a distinct accent and swing for testing?

In a drum SEQ view, hold ENV and tap a white step key to toggle that kit’s shared AC step. On HOME overview, KNOB2 adjusts the selected909 pattern’s swing, used across parts. Give the destination different markers before copying and confirm they survive the paste and Undo.

Does the copy survive saving and restarting?

The copied musical data is project data. A bounded physical909 full-copy test retained drum hits, shared accent step 2 and 60% swing after SAVE and a normal power cycle. This does not establish every instrument’s physical restart coverage. Back up first and verify your chosen workflow.

Can the computer inspect unsaved patterns without saving them?

Yes. This release adds command 49 to read current RAM. It does not call project save/flush, change patterns, edit notes, or alter Undo. CRCs and scan stamps reject corrupt, incomplete or changing scans. Reading requires playback stopped and keys/buttons released. Existing autosave can still operate independently; the query neither triggers nor postpones it.

How do I use the query and comparison tool?

Install Python 3 plus mido and python-rtmidi for USB reads. From the extracted bundle:

python tools/fm1_pattern_read.py read --patterns 5 7 --output before.json
# Perform the panel copy or Undo, then release controls.
python tools/fm1_pattern_read.py read --patterns 5 7 --output after.json
python tools/fm1_pattern_read.py compare before.json after.json

Use a new output filename each time. Compare uses local files only and excludes scan stamps and dirty state from musical equality; it separately reports project fingerprint changes. It covers the requested patterns, not all device settings. Read failure never falls back to export/save.

What can the read-only query see?

All 32 pattern slots,25 instrument lanes, notes/gates/ties/slides/bass accents, shared kit accents and swing, lengths/rates, bass direction/transpose/generator settings, BREAK metadata and pattern-owned motion/probability. Legacy, independent and expanded formats are supported. It is not a raw-memory peek or a full device backup.

Why not use project backup to inspect an unsaved edit?

The stopped project-export path can flush and save dirty edits. Use command 49 for read-only inspection. Continue using ordinary backups for recovery, with sample WAVs separately; backups omit samples, calibration and the reusable default bank.

What was tested on the physical device?

One FM1:909 full/kick/snare copy and Undo visually; destination AC step 2/swing 60 through copy/Undo and saved restart.303 A-only P5→P7 and 808KICK P1→P7 copies passed complete lane readback, source/other-lane isolation and Undo comparisons; the original project fingerprints returned after Undo. The808 test had empty accent rows and 50% swing, so distinct808 groove markers were not independently tested. All 25 scopes have local automated coverage, not all 25 hardware acceptance.

Can I turn off the internal303 and keep sending its MIDI?

Not yet. An independent internal-synthesis bypass is planned. Ordinary part mute suppresses outgoing sequence notes too. The planned control will preserve external note lifecycle while stopping selected internal synthesis.

Can the TRS socket send MIDI to a TD-3?

Current firmware sends MIDI over USB; its TRS jack receives. No selectable original-jack OUT feature is included. A laptop or compatible USB MIDI host can route FM1 output to aDIN/TRS MIDI output interface. The proposed Raspberry Pi router is a development target, not part of this firmware download.

Are weighted blocks, evolving probabilities or externalLFO controls included?

No. Existing per-step probability and motion remain available. Weighted block selection, slowly evolving block weights, named external devices and receiver-specific CC/LFO mapping are planned work.

Does this update the browser emulator or add native sample upload?

No emulator assets are changed by this release. The existing emulator and Slice Profiles tool retain their separate published state. There is no new native sample upload, USB recording or raw REX decoding in this package.

What about autosave and performance?

The separate note/tail-aware autosave fix is not included. Use existing AUTOSAVE OFF and deliberate manual saving where appropriate for external performance. No CPU savings from an internal-sound bypass are claimed because that control is not implemented. Heavy-load, broad receiver timing and long-soak acceptance remain open.

Where are the source, credits and rollback files?

Corresponding source, component notices and GPL licensing accompany the release. The complete bundle includes the previous public 0.1.6-beta1 firmware/source as a rollback option, not factory firmware. Keep a matching pre-update project backup; downgrade/restore is not physically qualified. Read installation and rollback before updating.

Can I play Slice Profiles sounds in the browser emulator?

Yes. Export a review project JSON from Slice Profiles. In the emulator, choose the same original WAV and that JSON, then Import WAV + slice settings. Switch on the panel, select a slice and audition it, or enter the original BPM and choose Play with FM1. Export review project keeps portable settings and needs the matching WAV. Inactive slices are skipped in group playback but remain individually auditionable.

The older emulator firmware engine is unchanged. This is a separate website update after 0.1.6 publication; frozen firmware and downloadable ZIPs remain as originally released. The native FM1 does not read review JSON or these per-slice settings. Its existing break uploader takes sample audio; a shaped-audio export compatible with its eight-slice break layout is still needed. Marker JSON is cuts/timing only. No raw REX decoder, sample recording or native hardware integration is included.

What is new in 0.1.6-beta1?

Independent block variations, deletion with Undo/Redo, visible SONG UNDO, 1–32-bar blocks and scale-safe 303 transposition. The firmware is the exact installed/tested package, identity FM-1_9000106. No new flash is needed on the development unit.

The separate Slice Profiles companion adds WAV hit detection and shaping in the browser. It is not integrated into the FM1's native sampler. A later browser update lets the emulator apply its review-project sound settings; see the browser playback section above.

What has been accepted?

Bounded hardware copy/delete/Undo/Redo, one independent kick edit, arrangement/kick recall, sequential playback, and one-note scale-safe MIDI comparison passed. A 32-bar block took about 64 seconds at 121 BPM (expected 63.47) and survived save/restart, then was restored to four bars and saved. Two arrangement cycles were reported clean. The browser snare-extraction and envelope workflow was accepted by the user as a useful experimental starting point.

Software/target checks and native scenarios passed. This is experimental evidence, not all-workload or stable-release qualification. Broader heavy-load, external MIDI and overnight checks remain open. Read the limits.

Can autosave interrupt external MIDI?

A glitch near an autosave and a new dropout were reported during editing with external MIDI. The event was not independently timestamped, but the source documents audio interruption during flash erase. The save guard checks the internal sequencer; incoming MIDI can still sound while that sequencer is stopped.

For external MIDI performance, stop the DAW, open GLO > PROJECT > AUTOSAVE, and set it OFF with ALGORITHM. Let the final preference save finish while stopped. Save manually between takes. OFF means subsequent unsaved edits may be lost on power-off. Disabling autosave is an existing feature; no new autosave switch was added in this optimization.

Does a sound strip add MIDI latency?

The sound-strip processor has no lookahead delay buffer. It can reshape the attack and tail, which can change the perceived groove. The separate optional master limiter has a 64-sample lookahead; it is not the individual strip limiter.

Separate isolated-kick recordings showed no clear added fixed attack delay with its strip ON. About 5.6–5.9 ms of attack-position standard deviation was measured across the complete MIDI/device/analog capture chain. A Reason buffer change altered recording placement, without materially reducing that variation. Digital loopback reproduced 167 attacks with a single fixed 27-sample shift and no added variation detected. This does not establish the source of the earlier variation or prove an FM-1-only timing fault. Further investigation is deferred from this experimental release; automatic latency calibration is not implemented.

How do I sequence the device from Reason?

Use the part's configured note channel under GLO > MIDI. Defaults are 909:10, 808:11, 303A:2, 303B:3 and BREAK:4. Notes and clock/transport are separate: sending notes does not require simultaneously running an internal pattern. Avoid concurrent internal notes if the intended test is external MIDI only.

Can I change each drum's incoming MIDI note?

Per-drum incoming note remapping is a recorded proposal. Current fixed mappings must be accommodated in the DAW. Use numeric MIDI note numbers because octave names vary between applications.

Can I load a Drum Monkey MIDI clip into a device pattern?

A direct Standard MIDI File importer is not included. A proposed converter needs mapping, destination preview and backup, and must report timing or velocity that the device pattern cannot represent. Four bars of 4/4 at sixteenth-note resolution use 64 steps; importing must also respect each drum's independent length/rate. Off-grid groove must not be silently discarded.

Where is the CC reference?

The matching source archive contains docs/ACULTUR8_CC_INVENTORY.json and the engine/control protocol docs. The optimization changes only inventory source hashes, not its 700 entries. Those entries include different device/browser contexts and are not a claim that 700 hardware CC numbers exist or that every mapping has physical acceptance. Are delay and reverb before or after compression?

Sound → individual strip → dry mix and reverb/delay sends → effects mixed with dry → master compressor/pump → remaining master/output stages. The individual limiter shapes the effects input; master compression processes dry and effect returns together. This order is fixed. Selectable routing is a proposal, not a feature in this build.

Does muting disable an engine and remove its CPU cost?

No such guarantee is made. Part mute suppresses internal sequencer triggers; tails, external MIDI and shared effects can still require processing. Explicit engine enable/disable and CPU-priority policies remain proposals.

Can I record separate drum stems?

Individual drum mutes exist. Automated sequential MIDI-controlled stem passes and complete mute/solo restoration are proposals. Shared compression and effect tails may make isolated stems differ from a full mix. Digital loopback captures software playback; physical FM-1 audio must first enter that playback mix or a separately configured recording mix.

What should I save before installing or reverting?

Preserve current projects, private samples and separate reusable strip defaults. The USB current-project export excludes the reusable default bank, private sample audio and calibration. Current-project strip persistence and reusable default recall are distinct checks. Use a brief SAVE tap for the project; do not confuse Save Default with Apply Default or rewrite the saved default during recall testing.

EXPAND is a one-way timing-format conversion. Older firmware may reject the expanded format. The provided 0.1.5 comparison baseline is not a promised overload fix; read the installation/rollback instructions before reverting. Do not erase or factory-reset to work around an unexpected format error.

How do I copy, delete and Undo blocks?

Open SONG, choose the source with BLOCK and choose DUP AS VARIATION in its controls list. SEL confirms; HOME cancels. Are blocks limited by pattern length?

With ARRANGEMENT ON, use BARS on the second SONG page, KNOB4, for 1–32 musical bars. This repeats stored patterns, not 32 unique bars of steps. Lanes remain at 64 steps. A 5-step lane can overlap a 16-step lane; the block ends at its chosen musical duration without waiting for their least common multiple. Unchanged pattern references continue phase; a changed part pattern restarts.

How does scale-safe transposition work?

Select the shared key/scale and set 303A or 303B ADHERE to SCALE. Transposition is corrected to an allowed note, with nearest-note ties choosing lower. Root/Chord remain separate modes. A bounded test with source A, MIDI 33, +1 transpose and C Ionian emitted 33 in Scale mode and 34 with adherence Off. This is not proof of every scale, range or MIDI input path. The requested plain MINOR label and new harmonic progression sequencer are not included.

How do Slice Profiles find and shape a snare?

Run a local server from the extracted package and open the browser companion. Load a WAV, choose a profile, inspect a short snare in the spectrum, and hear the detection band. Detection uses a sudden energy rise plus an absolute minimum band RMS dBFS level and minimum spacing. The filter guides detection; it does not remove other instruments from the saved source. Preview before replacing edits.

Magenta triangles show matched attacks. Orange lines show proposed cuts slightly earlier because of pre-roll/zero-crossing refinement; green is accepted/active. Grey indicates inactive slices or candidates below the level gate. A low floor such as −60 dBFS allows quiet spill; raise it for the recording. There is no universal snare frequency or dB threshold.

What settings belong to each slice?

CV/gate sequencing: think of a guitarist’s two hands

A guitarist combines two jobs: the picking or strumming hand supplies the rhythm, while the fretting hand helps choose the pitch through string and fret position. Our proposed split sequencer separates those jobs into two repeating lanes.

The gate lane is the picking hand: a trigger says “play now”, a rest says “do not pick”, and a hold keeps an existing note sounding. The pitch lane is the fretting hand: it chooses the note ready for the next trigger. In this first design, changing the pitch lane alone does not start a note.

Where is the volume for an individual drum?

Can each part have its own MIDI channel?

Yes. In GLO > MIDI, each part offers channels 1–16 or OFF. Default note channels are 909: 10; 808: 11; 303A: 2; 303B: 3; BREAK: 4. A part currently shares its assigned input/output note channel. CV/gate sequencing: think of a guitarist’s two hands

A guitarist combines two jobs: the picking or strumming hand supplies the rhythm, while the fretting hand helps choose the pitch through string and fret position. Our proposed split sequencer separates those jobs into two repeating lanes.

The gate lane is the picking hand: a trigger says “play now”, a rest says “do not pick”, and a hold keeps an existing note sounding. The pitch lane is the fretting hand: it chooses the note ready for the next trigger. In this first design, changing the pitch lane alone does not start a note.

Imagine an eight-step picking rhythm over a three-note fretting cycle: D → F → A. Both advance on the same tick in this example. The pitch updates first; a trigger then plays that pitch. The repeating pitch lane continues through rests.

Can my DAW groove the arpeggiator with MIDI trigger notes?

Requested feature, not implemented yet (FM1-46). An external MIDI gate mode will let a DAW note pulse advance the arpeggiator one position. Choose an input source, MIDI channel and trigger key, such as the key your DAW labels C-2. The UI should also show its numeric MIDI note, because octave labels differ between DAWs.

How do I play only the 909, or turn individual parts on and off?

On the device's HOME pattern screen, tap the first five black keys from the left to mute or unmute the five parts:

  • Black key 1: 909
  • Black key 2: 808
  • Black key 3: 303A
  • Black key 4: 303B
  • Black key 5: BREAK

Tap the same key again to unmute. To hear only the 909's internal sequence, leave 909 unmuted and mute 808, 303A, 303B and BREAK. Check the HOME display for the current mute state: do not blindly toggle a part that is already muted. Muting preserves the notes and sound settings. These mutes suppress internal sequence triggers; they do not switch an engine off or disable incoming MIDI notes. Existing ringing tails, synth/filter state and shared effects can still consume processing time until they become idle. Use the performance display to inspect actual load rather than assuming that mute means zero CPU.

On the LFO mixer PARTS page, black keys alone select a part; hold HOME and press its black key to mute it. On 909 MIX or 808 MIX, hold HOME and press a black key to mute that individual drum track instead. These are performance mutes; do not treat them as a saved global enable switch or a MIDI input-channel OFF setting. Ordinary performance mutes are not saved with the project; song-row mutes are separate.

Device and Reason workflow: practical questions from testing

Local FAQ update, 18 October 2026. These notes describe the installed 0.1.3-beta1 workflow and bounded observations from one FM1. Publication remains held. Older checkpoint sections on this page are historical; the observations here do not establish full release qualification.

Where is the volume for an individual drum?

Press LFO, choose 909 MIX or 808 MIX with SELECT, and select the drum with a black key. The four knobs control LEVEL, PAN, REV and DLY. Use LEVEL to balance sounds. Strip BOOST and the limiter have different jobs. The PARTS mixer provides the corresponding controls for the five whole parts. Individual drum levels were explored successfully during the physical session.

Why do externally played bass notes repeat after release?

Check the selected part's mixer DLY and REV sends before concluding that MIDI notes are stuck. During this session, 303B had DLY at 47%; returning it to 0 removed the repeating echoes. Reverb can leave a fading tail. A sustained or retriggering sound after tails fade still needs investigation; this example is not a universal stuck-note diagnosis.

Can each part have its own MIDI channel?

Yes. In GLO > MIDI, each part offers channels 1–16 or OFF. Default note channels are 909: 10; 808: 11; 303A: 2; 303B: 3; BREAK: 4. A part currently shares its assigned input/output note channel. NOTES OUT controls pattern note output, not permission to receive notes. Basic USB note response was heard for all five parts through Reason; arbitrary reassignment, full isolation, TRS and precise timing remain separate checks.

Which notes trigger drums and slices in Reason?

Use numeric MIDI notes when comparing software octave labels. The current drum maps are fixed. In Reason, C1 (36) triggers the kick and D1 (38) the snare on the chosen kit channel. On 909 channel 10, F-sharp1 (42) triggers closed hat and A-sharp1 (46) open hat. On 808 channel 11, G-sharp2 (56) triggers cowbell. BREAK channel 4 uses notes 36–43 for slices 1–8. These are mappings, not pitched transpositions of the drum sounds.

In the tested Drum Monkey export, notes appeared around C3. A duplicate clip was moved down two octaves to C1 for testing. Keep the original. A whole-clip shift only solves layouts with matching relative spacing; it is not proof of universal Drum Monkey compatibility. Configurable input maps remain a suggestion.

Will pressing Play in Reason start the FM1's own sequencer?

Incoming notes can trigger the FM1 while its internal sequencer is stopped. MIDI Start/Continue control transport; MIDI Clock supplies timing. For a notes-only test, keep the FM1 stopped and disable Reason's Options > Sync > Send MIDI Clock. Reason's clock-host mode also sends transport messages. The FM1's CLOCK OUT setting controls its outgoing sync. Avoid assuming an incoming-sync setting from that label. In the tested setup the FM1 became quiet after Reason stopped; this is not exhaustive transport or stuck-note qualification.

Can a Reason Combinator rotary control the FM1 without its page being open?

Yes for the tested parameter. A separate MIDI Out on channel 6, CC106 controlled 303B Delay Send, including while another FM1 page was open. CC values are 0–127. The adjacent 303B mixer addresses are CC104 Level, CC105 Reverb Send and CC107 Pan, also on channel 6; these adjacent controls have source mappings but were not individually accepted in this physical test.

Fixed CC control channels are independent of configurable note channels: keep 303B notes on channel 3 and use a separate control-only MIDI Out on channel 6. Disable Receive Notes for the control-only device in a Combinator. A labelled Combinator can make controls easier to identify; the hardware does not currently rename Reason's generic CC menus. Physical control surfaces, automation timing, pickup and the full CC map still need their own acceptance.

How do project Save, Save Default and Apply Default differ?

A brief tap of the physical SAVE button saves the project; watch for SAVED. Holding SAVE has copy/combination functions, so use a short tap for this operation. On a sound's STRIP DEFAULTS page, KNOB2 saves that sound's reusable default; KNOB3 applies its previously saved default. KNOB1 controls the overall strip enable. Do not use KNOB2 during a recall test.

303B low-pass, boost, ceiling, release and enable recalls were observed in this session. Its saved low-pass default recalled after a normal restart. All 25 current strip configurations matched across explicit project Save and a normal power cycle. These results do not prove every saved field, every default bank or complete sound/pattern/mixer persistence. The strip MIDI query reports project configuration, not the saved bank or actual audio DSP state.

How do I undo an edit?

Hold HOME and press REC for Undo; hold HOME and press PLAY for Redo. A 303A high-pass edit was physically checked through edit, Undo, Redo and final Undo, with the other strip settings unchanged. This does not claim every action has identical Undo coverage. To clear one part's sequence, select that part first, then hold SAVE and press REC. Check that the confirmation names the intended part and current pattern; press SEL to confirm or HOME to cancel. This was exercised on 303A in P1: the device reported CLEARED 303A and the note display became empty. Do not use the global CLEAR PATTERN action when you only want to clear one part. Clearing notes does not reset the selected sound or diagnose a sustained/overload-like sound; those require separate checks.

What does EXPAND mean, and why is returning to zero refused?

EXPAND upgrades the project's timing storage to the expanded rate format. The device also initializes independent lanes if required. Existing notes and starting timing are retained; it does not generate or extend notes automatically. It is currently a one-way conversion: requesting zero is deliberately refused. The rotary 0/1 presentation and generic RATE CHANGE REFUSED message are misleading; clearer action/status wording is a recorded UI issue, not a fix already present. Preserve a private project backup before conversion. Older firmware cannot be assumed to load the expanded format.

Why do all drum rows appear shortened when only the kick length changes?

Known display issue: the grid uses the selected drum's length to shade all rows. During this device test, BD was set to 6 steps, SD to 8, and reselecting BD still showed 6. Thus the settings were independent even though the shading suggested otherwise. A per-row rendering correction is recorded for review. Subsequently, switching between BD and SD during internal playback showed their position indicators cycling independently over six and eight steps. This is physical visual timing evidence; a subsequent explicit Save and normal power cycle retained BD at six steps and SD at eight, both at 1/16. Measured audio/MIDI onset timing and all-lane persistence remain unverified.

Why do all drum rows appear to share a playhead?

Known display issue: the current grid reuses the selected drum lane's position for every row. It does not yet show a separate moving playhead for each drum's own length and rate. The requested correction is recorded for review; independent kick/snare timing settings, selected-lane cycling and persistence were checked separately. A shared display highlight is not a measurement of each audio clock.

Does the delay already filter its repeats?

TONE low-pass filters the feedback loop. DLY LOW CUT, in the FX SEL list, high-pass filters the incoming delay signal. Tape mode adds saturation and a fixed low-frequency/DC filter. A separately adjustable feedback high-pass and explicit low-pass cutoff are suggestions for review; filtering alone is not a guarantee against excessive feedback.

Can I record individual sounds as stems?

Individual drum mutes exist. Automated sequential capture is a future proposal: record one continuous audio track while MIDI isolates each sound for equal 16-, 32- or 64-bar passes, then split and align those sections afterward. Automatic DAW track creation is not required. Full-device solo isolation, MIDI operation, repeatable starts, prior mute restoration and effect tails need review and hardware testing. Shared effects and compression may change when sounds are isolated. Automated capture is not yet implemented or accepted.

What did the playback overload checks establish?

At 125 BPM, short clap-strip OFF/ON/OFF comparisons added 0/32/0 dropouts. Two five-minute runs with the clap strip OFF added none, including one after Save and restart. The OFF setting persisted, the clap level was unchanged, and a separate brief listening check sounded normal. The load guard remained active. This supports a workaround for that tested setup; it does not establish a general fix, sufficient headroom, or a sole cause.
