0.1.5-beta1 INSTALL / ROLLBACK GUIDANCE

1. Preserve projects, samples and separate reusable strip defaults. Stop the DAW
 and FM1 transport, lower MASTER, keep stableUSBpower and avoid concurrent MIDI
 apps accessing the updater port. Review the backup exclusions in KNOWN_ISSUES.
2. Verify the package SHA256 against SHA256SUMS.txt.
3. Install Python 3 and the MIDI dependencies, then use the included script:
 python -m pip install mido python-rtmidi
 python fm1_install.py x0x-0.1.5-beta1.fwsc --port "X0X FM-1"
 Follow its prompt. Do not add --force merely to bypass an unexpected error.
4. After restart, independently query:
 python fm1_install.py --info --port "X0X FM-1"
 Expected identity:FM-1_9000105. Begin quiet, bounded testing before important use.

Prior baseline package x0x-0.1.3-beta1.fwsc is supplied under rollback/ with its
matching baseline-source archive. It is the previously installed comparison
baseline, not a claimed fix for overload and not manufacturer factory firmware.
Back up first: source format compatibility may prevent older builds loading an
expanded project. Use the same installer with the chosen rollback file, then
verify FM-1_9000103. The earlier0.1.4->0.1.3recovery was physically verified;
0.1.5->0.1.3rollback has not yet been physically exercised.

Manufacturer factory firmware is a separate route:
 https://www.m-vave.com/download (PCFirmware > FM-1)
No factory restore, destructive reset or private flash image is bundled here.
Do not interrupt a firmware update or flash save. If identity/recovery fails,
retain logs and follow the upstream recovery instructions in the source manual.
