Which MIDI channel do I send notes to?

Choose the FM-1 as the output destination in your DAW or MIDI controller, then send Note On events to the part’s channel below. These are the firmware defaults, using channel numbers 1–16.

InstrumentDefault channelNotes to sendGLO → MIDI setting
909 drum machine10Drum notes; kick = 36, snare = 38.909 MIDI CH
808 drum machine11Drum notes; kick = 36, snare = 38.808 MIDI CH
303 A2Pitched notes. Send Note Off to release the held note.303A MIDI CH
303 B3Pitched notes. Send Note Off to release the held note.303B MIDI CH
Slice sampler / BREAK4Notes 36–43 trigger slices 1–8 respectively. Send Note Off to release.BREAK MIDI CH

Already changed your channels? Check GLO → MIDI and use the displayed part channel instead. 0 / OFF disables that part’s note input/output. These configurable note channels are separate from the control-specific CC channel/address assignments in the searchable inventory below.

Example: send Note On, channel 11, note 36, velocity 100 to play the 808 kick. Velocity must be greater than zero; Note On with velocity 0 is treated as Note Off. Note numbers are shown numerically because DAWs use different octave names.
